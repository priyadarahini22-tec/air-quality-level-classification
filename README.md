# air-quality-level-classification
# Air Quality Level Classification Using Machine Learning

## Project Overview
This project classifies air-quality levels using machine-learning algorithms based on pollutant measurements.

## Objectives
- Collect air-quality data for Chennai.
- Clean and analyse the dataset.
- Visualise pollutant trends.
- Train Decision Tree and Random Forest classifiers.
- Compare model performance using accuracy, precision, recall and F1-score.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Plotly
- Scikit-learn
- Open-Meteo Air Quality API

## Machine Learning Models
1. Decision Tree Classifier
2. Random Forest Classifier

## Project Files
- `Air_Quality_Level_Classification.ipynb` — project notebook
- `chennai_air_quality_cleaned.csv` — cleaned dataset, if included

## How to Run
1. Download the notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Run the cells in order.

## Data Source
[Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api)

## Disclaimer
This is an educational project. The model's predictions are not a substitute for official air-quality measurements or public-health guidance.
